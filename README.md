# 中国象棋（网页版）

纯前端实现的中国象棋，支持 **双人对战**、**人机对战** 与 **用户设置** 三大模块，
并由个性人物 **「廖老爷」** 全程评棋、支招，零依赖，可直接用浏览器运行。

> 🎭 **「廖老爷」**：本程序的个性形象、棋评人，**也是人机对战中的 AI 对手**。
> 形象文件为 `src/resources/liaolord.gif`，遍布标题、顶栏、侧栏形象卡、AI 对手卡、
> 评语面板、AI 支招播报与设置页签。
>
> 🗣️ **犀利评语**：廖老爷点评时而夸赞、时而毒舌，玩家走出坏棋（如白送大子）会毫不客气
> （"臭棋篓子的味道出来了"），悔棋也有调侃，为对局增添趣味。

## 运行方式（重要）

> ⚠️ **请勿直接双击 `src/index.html` 打开！**
>
> 本项目使用 ES Modules，浏览器在 `file://` 协议下会因 CORS 限制**拒绝加载 JS 模块**，
> 表现为：**看不到棋盘、按钮全部点不动**。必须通过本地服务器访问。

### 一键启动（推荐）

**Windows**：双击项目根目录的 `start.bat`，会自动启动服务器并打开浏览器。

**任意系统**：

```bash
# 方式 A：使用项目自带的零依赖服务器（需要 Node.js）
node tools/server.js 8080 src
```

```bash
# 方式 B：使用 Python
python -m http.server 8080 --directory src
```

```bash
# 方式 C：使用 npx
npx serve src
```

然后浏览器访问 **http://localhost:8080**（`file://` 方式不可用）。

## 功能模块

### 1. 双人对战
- 棋盘与棋子渲染（Canvas 绘制棋盘 + DOM 渲染棋子）
- 完整的中国象棋走子规则（车、马、炮、相、仕、帅、兵的合法走法，含蹩马腿、塞象眼、将帅照面、过河兵等）
- 将军 / 绝杀 / 困毙 / 三次重复局面的胜负判定
- 悔棋（步数可配置、**每局次数上限可配置**）
- 走棋动画、吃子特效、将军抖动、上一步高亮
- **AI 支招**（仅双人模式）：调用大模型给出建议走法，以箭头标注，不自动落子，**每局次数上限可配置**
- **「廖老爷」评棋**：以「廖老爷」口吻点评走子——吃子、将军、妙手、开局/中局/残局、终局胜负，
  并对**明显失误**（白送大子）给出犀利毒舌点评；悔棋时亦有调侃

### 2. 人机对战
- 与模块 1 相同的渲染、规则、悔棋、特效
- AI 通过设置中的 `base-url` + `api-key` 调用大模型走子
- **「廖老爷」即 AI 对手**：右侧显示对手卡（形象 + 执子方 + 即时状态），
  思考时显示「廖老爷思考中…」，落子均以其口吻播报
- 人机模式下悔棋会自动回退到轮到玩家走子的状态

### 3. 用户设置
- **AI 设置**：base-url、api-key、模型名、temperature、超时；提供智谱 GLM 示例；支持「测试连接」
- **悔棋设置**：是否允许悔棋、每次悔棋步数、**是否限制每局次数**、每局最大悔棋次数
- **AI 支招设置**：是否启用、是否显示箭头、**是否限制每局次数**、每局最大支招次数
- **界面与走棋设置**：棋盘主题（木纹/水墨/暗夜/竹青）、棋子样式、坐标显示、上一步高亮、走子记录、动画开关、特效开关
- **廖老爷设置**：是否启用评语、是否显示形象、AI 支招是否以「廖老爷」口吻播报、是否点评每步走子、评语展示时长

所有设置保存在浏览器 `localStorage`，刷新后保留。

## AI 如何决策（本地搜索 + 大模型）

为兼顾「算度准确」与「棋理正确」，AI 采用**混合架构**：

1. **本地搜索引擎**（`src/js/ai/search.js`，零依赖）
   - 极小极大 + Alpha-Beta 剪枝，**静态搜索（quiescence）**消除「吃子后又被吃回」的视界效应
   - **置换表（transposition table）**缓存已搜索局面，提升深层算度效率
   - 局面评估含子力价值、位置表、**机动性**与**将帅安全**（缺士怕马、缺象怕炮）
   - 负责短距离精确算度：吃子、解将、避免送子
   - 对开局无谓兑子施加惩罚
   - **绝杀短路**：本地算得必杀着时直接落子，省去一次大模型往返
2. **大模型**（`src/js/ai/engine.js`）
   - 接收「局面 + 走子历史 + 带评分排序的合法走法清单（含中文记谱与战术标注）」
   - 负责棋理判断：开局定式、中局战术意图、残局杀法
   - 最终决策者，可推翻本地引擎的建议

走法清单会按本地引擎评分**从高到低排列**并标注战术要点（如 `【将军】`、`【吃車】`、`【可能被吃】`），大模型据此做最终选择。搜索深度可在「设置 → AI 设置 → 本地搜索深度」调整（1~4，推荐 2~3）。

## AI 配置示例（智谱 GLM）

在「设置 → AI 设置」中：

| 字段 | 值 |
|------|-----|
| Base URL | `https://open.bigmodel.cn/api/paas/v4` |
| 模型名称 | `glm-4-flash`（或 `glm-4-plus`） |
| API Key | 前往 [open.bigmodel.cn](https://open.bigmodel.cn) 控制台获取 |

也可点击「填入智谱示例」自动填充 Base URL 与模型名。

> ⚠️ **安全提示**：本项目的 AI 调用为**前端直连**，API Key 会随请求暴露在浏览器端。
> 仅建议在本地或可信环境使用，不要在公网部署时填入真实密钥。

## 目录结构

```
src/
├── index.html              # 页面入口
├── resources/              # 人物形象资源（「廖老爷」）
│   └── liaolord.gif
├── css/
│   └── style.css           # 样式与主题
└── js/
    ├── app.js              # 应用主控（串联引擎与 UI）
    ├── core/
    │   ├── constants.js    # 常量、棋子定义、初始布局
    │   ├── board.js        # 棋盘模型
    │   ├── rules.js        # 走子规则引擎
    │   ├── game.js         # 游戏状态机（走子/悔棋/胜负）
    │   ├── notation.js     # 中文记谱（前后消歧，单一事实来源）
    │   ├── persona.js      # 「廖老爷」个性形象与评语系统
    │   └── settings.js     # 设置管理（localStorage）
    ├── ai/
    │   ├── client.js       # 大模型 HTTP 客户端（OpenAI 兼容）
    │   ├── search.js       # 本地搜索（Alpha-Beta + 静态搜索 + 置换表）
    │   └── engine.js       # 提示词构造、走法解析、AI 走子/支招
    └── ui/
        └── renderer.js     # 棋盘渲染器（棋盘/棋子/标记/特效/箭头）
tests/
├── run-all.mjs             # 测试聚合入口（npm test）
├── engine.test.mjs         # 核心规则引擎测试
├── ai.test.mjs             # AI 提示词与解析测试
├── search.test.mjs         # 本地搜索质量测试（绝杀/送子/置换表）
├── limits.test.mjs         # 悔棋/支招次数限制测试
└── persona.test.mjs        # 「廖老爷」个性化测试
```

## 坐标约定

- `row`：0..9，自上而下。`row=0` 为黑方底线，`row=9` 为红方底线。
- `col`：0..8，自左向右。
- 红方先行。
