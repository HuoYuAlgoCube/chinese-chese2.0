设置

配置大模型接口，用于人机对战与 AI 支招。所有 AI 功能均通过此处的 base-url 与 api-key 调用。

走子由「本地搜索引擎 + 大模型」共同决定：本地引擎负责精确算度与战术打点，大模型负责棋理与开局判断。深度 2 约看一回合，深度 3 更强但更慢。

智谱 AI 示例（GLM）
  • Base URL：https://open.bigmodel.cn/api/paas/v4
  • 模型：glm-4-flash / glm-4-plus
  • API Key：前往 open.bigmodel.cn 控制台获取

注意：前端直连会暴露 API Key，仅建议在本地或可信环境使用。

人机模式下，悔棋会自动回退到轮到你走子的状态。

在双人对战中点击「AI 支招」，会由大模型给出当前走子的建议，不自动落子。

廖老爷
象棋阁主，本程序的个性形象与棋评人。
开启后，人机对战中廖老爷每走一步会额外生成一句「自评」（多 1 次 API 请求）；关闭则只播报落子。

「廖老爷」会在对局中点评走子、将军与胜负，并在 AI 支招时以其口吻给出建议；评语会明确标注点评对象（红方／黑方／廖老爷自评）。形象取自 resources 文件夹。
